Нейросеть и ключ

Как получить Gemini API key — пошагово
  1. Откройте Google AI Studio — API keys. При необходимости войдите в Google-аккаунт.
  2. Нажмите Create API key (Создать API-ключ). Если предложат выбрать проект, выберите или создайте проект.
  3. Скопируйте созданный ключ целиком. Не публикуйте его и не отправляйте посторонним.
  4. Вернитесь в «Проверь Д/З», вставьте ключ в поле «Ключ нейросети» и выберите Gemini. Ключ сохраняется локально в браузере/приложении.
  5. Если API недоступен из вашей сети, используйте VPN и повторите. Бесплатный тариф имеет лимиты и доступность зависит от региона и модели.

На бесплатном тарифе запросы могут использоваться Google для улучшения продуктов. Не загружайте персональные или конфиденциальные данные.

Безопасность ключа. Не используйте приложение на общих или чужих устройствах: ключ хранится в открытом виде в памяти браузера. Для учебного класса заведите отдельный ключ с лимитом расходов и очищайте историю после урока.

Разбор строит нейросеть, возможны неточности. Спорные случаи проверяйте по учебнику.
