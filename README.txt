ВАЖНО ПРО КЛЮЧИ API
----------------------
Ключи нейросетей — персональные. Вводите их в приложении на своём устройстве.
Не публикуйте ключи в GitHub, не встраивайте их в APK и не отправляйте другим.
Веб-версия хранит ключ в localStorage браузера на устройстве.


ВАРИАНТ 1. ЗАПУСК НА ПК (Windows)
------------------------------------
1. Распакуйте ZIP в отдельную папку, например C:\\Proverdz.
2. Установите Python 3 с официального сайта python.org, если он ещё не установлен.
   При установке Windows отметьте «Add Python to PATH».
3. Откройте папку проекта, щёлкните адресную строку проводника, введите cmd и Enter.
4. В командной строке запустите:
       python server.py
   Если команда python не распознаётся, попробуйте:
       py server.py
5. В браузере откройте:
       http://localhost:8000
6. Перейдите в «Настройки» → «Нейросеть и ключ», выберите провайдера,
   вставьте личный API-ключ и сохраните его (поле ключа).
7. Вернитесь в «Проверка», загрузите фото/файл или используйте камеру и нажмите
   кнопку проверки.
8. Чтобы завершить работу, вернитесь в окно командной строки и нажмите Ctrl+C.

Не закрывайте окно терминала во время использования сайта. Сервер привязан к
127.0.0.1 (только локальный компьютер); не выставляйте его наружу в интернет.


ВАРИАНТ 2. СОБРАТЬ APK БЕСПЛАТНО ЧЕРЕЗ GITHUB ACTIONS
---------------------------------------------------------
1. Войдите в GitHub и создайте новый репозиторий. Для workflow удобнее Public.
2. Загрузите содержимое ZIP целиком в корень репозитория. Обязательно сохраните
   скрытую папку .github и файл .github/workflows/build-apk.yml.
3. Откройте вкладку Actions. Если GitHub попросит разрешить Actions, подтвердите.
4. Выберите workflow «Build APK» → Run workflow → Run workflow.
5. Дождитесь зелёного завершения процесса. Откройте завершённый запуск.
6. Внизу страницы найдите Artifacts и скачайте «proverdz-apk».
7. Распакуйте артефакт ZIP. Внутри будет app-debug.apk.
8. Перенесите APK на Android, откройте его и разрешите установку из этого источника,
   если Android спросит. После установки можно удалить APK-файл.

Для обновления APK повторяйте запуск workflow после загрузки изменённых файлов.


НАСТРОЙКА НЕЙРОСЕТЕЙ
-----------------------
GigaChat:
• Откройте developers.sber.ru, создайте/откройте проект GigaChat API и получите
  ключ авторизации.
• Вставьте ключ в настройки Proverdz.
• Для GigaChat в сборке APK может требоваться сертификат Минцифры. Workflow
  пытается получить сертификаты автоматически. Если сертификат не скачался,
  сборка может завершиться, но соединение GigaChat работать не будет. Сверяйте и
  скачивайте сертификаты только с официального ресурса Госуслуг:
  https://www.gosuslugi.ru/crt

Gemini:
• Перейдите в Google AI Studio и создайте API key:
  https://aistudio.google.com/app/apikey
• Вставьте личный ключ в настройках. Доступность и бесплатные лимиты зависят
  от региона, модели и правил Google; VPN не гарантирует доступ или бесплатность.
DeepSeek:
• Создайте ключ на платформе DeepSeek:
  https://platform.deepseek.com
• API может быть платным, проверьте баланс, цены и лимиты перед использованием.


ОГРАНИЧЕНИЯ И ПРИМЕЧАНИЯ
----------------------------
• Тест синтаксиса JavaScript/Python — не то же самое, что полный тест реального API.
  Для end-to-end проверки нужен действующий личный ключ и доступ к сервису.
• Поддерживаемые форматы зависят от сценария: фотографии JPG/PNG/GIF/WebP;
  документы .pptx, .docx, .txt, .md, .csv (смотрите подсказки внутри приложения).
• Не используйте сервер.py как публичный сервер: он предназначен для локального запуска.
• Для чувствительных школьных работ учитывайте, что при проверке изображение/текст
  отправляется выбранному провайдеру нейросети.
